# DRS Dents

Вмятины на кузове из DRS Street для любого сервера с Custom Shaders Patch (Emperor ACSM, обычный `acServer`). Это **CSP online script**: игрокам ничего ставить не нужно.

- После удара металл машины вдавливается. Вмятину видят все игроки, которые видят эту машину; новичок, зашедший позже, тоже её видит.
- На физику это не влияет: повреждения в гонке по-прежнему считает сама игра (`DAMAGE_MULTIPLIER`).
- Машина чинится, если простоять 3 секунды в боксах, по команде `!repair` (стоя на месте), а также с началом новой сессии.
- Мнутся только машины с **открытой** моделью. Зашифрованный CSP kn5 (`__AC_SHADERS_PATCH_KN5ENC_v1__` в конце файла) не мнётся.

Каждый клиент судит только **свою** машину и рассылает остальным список её вмятин одним online event. Слот получатель берёт из отправителя события, поэтому помять чужую машину нельзя.

## Подключение (ACSM → Custom Shaders Patch → Extra Options)

```ini
[SCRIPT_0]
SCRIPT = 'https://raw.githubusercontent.com/sergfirst7/Oval_Racing_System/<commit>/oval.lua'

[SCRIPT_1]
SCRIPT = 'https://raw.githubusercontent.com/<repo>/<commit>/dents.lua'
```

Настройки можно дописать в блок `[SCRIPT_1]`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `depth` | 1 | глубина вмятин: 1 как у машины пилота в DRS Street, 0.5 вдвое мельче |
| `minKmh` | 14 | удар о машину медленнее этого (по разнице скоростей) следа не оставляет; для стены порог 35 |
| `floorCm` | 10 | удар не дальше этого (см) от низа машины считается касанием днищем (приземление после прыжка, кочка) и вмятины не даёт |

Проверить, что скрипт загрузился: в логе CSP должна быть строка `[DRS Dents] DRS Dents 1.2 loaded, online events on`.

## Сборка и тест

`dents.lua` собирается, руками его не править:

```
node build.js            # src/head.lua + DRS_Street client/lua/DRS_Dents.lua (origin/main) + src/tail.lua
node tests/run.js tests/dents_test.lua
```

Работа с сеткой (`DRS_Dents.lua`) берётся из DRS Street без изменений, поэтому её исправления попадают сюда при пересборке.

## Что не проверено в игре

- что online event со списком из 12 вмятин (137 байт) проходит через обычный сервер AC (там лимит 175 байт и одно сообщение в 200 мс);
- что новичку, зашедшему позже, CSP переотправляет последний список (`repeatForNewConnections`);
- вид вмятин и FPS на тяжёлых моделях (у NASCAR Next Gen основной kn5 весит 68 МБ).
